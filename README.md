##  And there they are ...

### 🎧 Vocodio

Do you know Anki? It's the same principle but audio-based because we are not all visual learners. Precisely, it's a vocabulary-learning web application inspired by AnkiDroid. You can create your own audio flashcards, import them from Excel or generate them automatically.
So why not learn a new language?
A little bonus: you can download the generated audio track and practice on the go, while commuting to work or school, walking, exercising, or traveling.

ᯓ★ Zoom in
- Python / Flask
- Ollama + Qwen3 for AI-generated vocabulary
- Piper TTS for local text-to-speech
- SQLite / SQLAlchemy
- Excel vocabulary import with pandas / openpyxl
- Audio processing with pydub / FFmpeg
- User authentication with Flask-Login / Flask-Bcrypt
- Custom repetitions, pauses and voices
- Local open-source AI integration

### 🧾 Scanify

Managing your expenses is hard? Especially as a student, when you have 10 assignments, a group project, and a lot of rice waiting for you to have time, relying on sandwiches to keep you alive, you don't count how much you spend, but don't worry, Scanify is here to help you. You just have to take a picture of your receipt or import your online receipt and it does all the work for you. While you finally have some time for rice, you get a nice overview of your monthly expenses, where you spend, how much per category and so on.
Your personal receipt analysis is ready in no time!

ᯓ★ Zoom in
- Python / Flask
- OCR with Tesseract
- Expense analysis
- Data visualization
- Receipt processing
